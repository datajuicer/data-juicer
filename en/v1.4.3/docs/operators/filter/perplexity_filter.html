perplexity_filter¶

Filter to keep samples with perplexity score in a specified range.

This operator computes the perplexity of text samples using a Hugging Face tokenizer and a KenLM language model. It keeps samples with perplexity scores within the specified minimum and maximum values. The perplexity is calculated character-based by default. If the perplexity is already computed, it will be reused from the ‘perplexity’ field in the sample’s stats. The operator supports batched operations for efficiency.

用于保留指定困惑度范围内的样本的过滤器。

该算子使用 Hugging Face 分词器和 KenLM 语言模型计算文本样本的困惑度。它保留困惑度分数在指定最小值和最大值范围内的样本。默认情况下，困惑度是基于字符计算的。如果困惑度已经计算过，则会从样本的 stats 中的 ‘perplexity’ 字段重用。该算子支持批量操作以提高效率。

Type 算子类型: filter

Tags 标签: cpu, text

✨ explanation 解释¶

This example demonstrates the PerplexityFilter operator in its simplest form, filtering out text samples with a perplexity score higher than 900. The output data only contains the samples that have a perplexity score less than or equal to 900. 此示例展示了PerplexityFilter算子最简单的使用方式，过滤掉困惑度分数高于900的文本样本。输出数据只包含那些困惑度分数小于或等于900的样本。

✨ explanation 解释¶

In this example, the PerplexityFilter operator is used with an additional context argument set to True. This allows the operator to also return the tokenized words (context) for each kept sample. However, the displayed output data only shows the final filtered text samples, similar to the ‘test_en_case_default’ method. The actual raw output from the operator includes both the filtered text and their corresponding tokenized contexts, but these are not shown in the provided output data. 在此示例中，PerplexityFilter算子使用了一个额外的上下文参数，并设置为True。这使得算子还能返回每个保留样本的分词结果（上下文）。但是，显示的输出数据只包含了最终过滤后的文本样本，类似于’test_en_case_default’方法。算子的实际原始输出包括过滤后的文本及其对应的分词上下文，但在提供的输出数据中并没有展示这些信息。
